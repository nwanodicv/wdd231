VijuTech - Website Project Plan

Site Name

VijuTech

This name was selected as it reflects modern personal tech exploration and provides a professional identity for a technology-focused site.

Site Purpose

The website will showcase modern tech gadgets, providing users with product info, specs, prices, ratings, and comparisons. The site will include a gadget list dynamically generated from JSON using JavaScript, as well as a form for inquiries or product interest submissions.

Scenarios

Visitors might ask questions such as:

  • “Which gadgets are trending and worth buying this year?”
  • “Can I see the specifications of different smart devices in one place?”
  • “How do I contact VijuTech or submit an inquiry?”

Color Scheme

Planned site color palette:

Primary Blue (#228B22) — used for headers, nav bar, buttons

Soft Light Gray (#f5f7fa) — used for backgrounds

Dark Gray (#222) — used for paragraph text

Typography

Primary Font: Roboto — for body text

Secondary Font: Montserrat — for headings and UI elements
